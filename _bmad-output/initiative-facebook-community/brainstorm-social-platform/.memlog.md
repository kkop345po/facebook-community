- (decision by coach) 規劃部署：React 由 Workers Static Assets 提供，Flask 優先驗證 Python Workers 相容性；傳統 Python 資料庫驅動若不相容採 Cloudflare Containers（需付費方案），PostgreSQL 使用外部託管，容器經 TLS 直連，不預設可使用 Hyperdrive Python 驅動。
- (insight by coach) Cloudflare 官方已有 Flask Python Workers 文件，但 PostgreSQL 驅動需實證。workers.dev 是平台提供的網址；隨機 trycloudflare.com 僅短期展示。Resend 對一般用戶發信需自有已驗證寄件網域，不能拿 workers.dev 當寄件網域。
