## 可開啟的網站

https://insulin-hosted-madonna-mega.trycloudflare.com

Cloudflare Quick Tunnel 連到本機 Waitress／Flask，React 介面由同一服務提供，PostgreSQL 位於本機專用 port 55438。首頁 HTTP 200；公開 `/api/health` 回傳 PostgreSQL、ok、版本0.1.0。已以公開網址在瀏覽器登入及互動，不只檢查本機。

此網址需電腦、資料庫、Flask 與 Tunnel 保持執行；重新建立 Tunnel 後網址可能改變。未啟用付費資源。Cloudflare MCP OAuth 已確認登入，作用域限基本帳號與 Workers 腳本；沒有要求 Account API Tokens Write 或帳務權限。MCP 不參與 Quick Tunnel 運作。

## 測試帳號及真實寄信界線

`TEST-ACCESS.md`有兩個由本機管理工具建立、核准的合成測試帳號與隨機密碼，僅分享給指定測試者。這些帳號未透過 Email 收信驗證，不算 Resend 送達成功的證據。介面驗收專用帳號及其內容在交付前清除。

新註冊帳號仍須驗證信箱。Resend金鑰已填且確認僅有寄信權限，MAIL_FROM目前為onboarding@resend.dev測試寄件者，不能寄給一般使用者；使用者目前無自有寄件網域。寄給一般用戶須另完成網域驗證，不能使用任意 Gmail 或 example.com。缺少設定時，畫面明確提示寄信未就緒；不自動繞過驗證。

## 再次啟動

在本資料夾執行 `./Start-Connect.ps1` 可啟動專案資料庫、保留／建立 Tunnel、更新公開網址及重啟網站。它只處理此專案的獨立資料庫和記錄的程序，不修改原本port5432的PostgreSQL服務。

修改 `.env` 的寄信欄位會被背景寄信工作讀取；更換 PUBLIC_URL 或 Cookie 安全設定後以 `./Restart-Web.ps1` 重啟。請勿把`.env`、`.pgdata`、`.runtime`或TEST-ACCESS.md上傳公開儲存庫。
